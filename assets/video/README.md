# 环节短片

视频文件**直接丢进这个目录**就能用，不走上传、不进 Supabase Storage，也就没有
50MB 单文件上限。这里是 Vite 的 `publicDir`（`vite.config.ts`），所以
`assets/video/sponsor.mp4` 的运行时路径就是 **`/video/sponsor.mp4`**。

## 用法
1. 把片子放进来，例如 `assets/video/sponsor.mp4`。
2. 运维台 →「环节 & 名单管理」→ 新建一个环节（如「赞助商短片」），
   `排序` 填成比「颁发感谢状给赞助商」小一点，**环节短片**填 `/video/sponsor.mp4`，
   点「保存环节」。
3. 到时候点这个环节的「▶ 上台」即播。播完停在最后一帧，等你切下一个环节。

## 格式
- **MP4（H.264 + AAC）** 最稳，浏览器全都认。`.webm` 也行，`.mov` / `.avi` 不要。
- 分辨率 1080p 足够；大屏是横屏，片子也用横屏。

## 声音
浏览器不允许带声音的视频自动播放，除非页面被真人点过。
**开场前在大屏上随便点一下**，之后全场都能带声自动播。
忘了点也不会卡住——会先静音播出去，画面下方提示「点一下大屏开启声音」，点了就有声。

## 线上部署要注意
本地跑（`npm run dev`）没有任何限制。若大屏走的是部署好的站点：
- 文件要提交进 git 跟着一起部署；
- **Cloudflare Pages 单文件上限 25MB**，超了就传不上去 —— 这种情况把片子放自己的
  CDN / 对象存储，然后在「环节短片」里填完整外链（`https://…/sponsor.mp4`），
  字段本来就支持直链。
